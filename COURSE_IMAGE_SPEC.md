# Course Thumbnail Image Spec (Design Team)

Use this spec for all **course thumbnail** assets so they display consistently across the app.

## Required dimensions

| Use            | Size (pixels) | Aspect ratio |
|----------------|---------------|--------------|
| **Standard**  | **1280 × 720** | **16:9**     |
| Retina (2×)   | 2560 × 1440   | 16:9         |

## Rules

- **Aspect ratio:** Always **16:9** (horizontal). All course images in the app use this ratio.
- **Format:** JPG or PNG. Prefer JPG for photos to keep file size small.
- **Safe zone:** Keep important content (text, faces, logos) within the center; edges may be cropped on some screens.
- **Min resolution:** 1280×720 px. For retina displays, provide 2560×1440 px.

## Where it’s used

- Home: Featured courses, top running courses  
- Explore / Courses list  
- Course detail page (hero, trailer poster, related courses)  
- Instructor: My courses  
- Admin: All courses, course detail  
- Cart sidebar  
- Student: My courses  

All of these use the same **16:9** crop; only the displayed size changes.

## Summary for design team

**Course thumbnail: 1280 × 720 px, 16:9.**
